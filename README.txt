ODIN COFFEE 웹사이트 파일

1. index.html과 odin-coffee.svg를 같은 폴더에 둡니다.
2. index.html을 웹호스팅/서버에 업로드하면 됩니다.
3. 연결 링크
   - Instagram: https://www.instagram.com/odincoffee_2025/
   - Online Store: https://smartstore.naver.com/odincoffee

구현 사항
- 원본 SVG의 내용과 레이아웃을 수정하지 않음
- 빨간 Instagram / Online Store 버튼 위치에 투명 클릭 영역 추가
- 모바일 반응형 적용
- SVG 원본을 그대로 사용해 텍스트와 벡터 아이콘 선명도 유지
- 키보드 접근성 및 새 창 보안 속성 적용
