1. index.html, style.css, odin-page.svg 세 파일을 같은 폴더에 둡니다.
2. index.html을 브라우저에서 열거나 웹호스팅에 그대로 업로드합니다.
3. 현재 연결 주소
   - Instagram: https://www.instagram.com/odincoffee_2025/

4. 주소를 바꾸려면 index.html의 각 <a href="..."> 부분만 수정하세요.
