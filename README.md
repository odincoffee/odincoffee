# ODIN COFFEE 웹사이트

최종 디자인 SVG를 기반으로 만든 반응형 단일 페이지 웹사이트입니다.

## 실행

`index.html`을 브라우저에서 열면 됩니다.

로컬 서버 사용 예시:

```bash
python3 -m http.server 8000
```

그 후 `http://localhost:8000`에 접속합니다.

## 파일 구성

- `index.html` — 페이지 구조와 클릭 링크
- `styles.css` — 반응형 레이아웃과 접근성 스타일
- `assets/odin-webend.svg` — 최종 디자인 원본

## 연결된 기능

- Instagram
- Naver Smart Store
- 전화
- 이메일
- 주소 지도 검색
